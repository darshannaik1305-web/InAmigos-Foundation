# InAmigos Foundation NGO Awareness Landing Page

A premium, highly interactive, and responsive landing page built for the **InAmigos Foundation**—a Section 8 registered social welfare non-profit organization working towards education, women empowerment, environmental sustainability, food drives, and animal welfare across India.

---

## 🌟 Key Features

* **Premium Glassmorphism UI**: Uses modern CSS variables, harmonious gradients (Emerald & Indigo), glass overlays, and hardware-accelerated animations for a top-tier visual experience.
* **Trust & Certification Ribbon**: Showcases official accreditations including CSR-1, NITI Aayog, ISO 9001:2015, and 80G & 12A certifications.
* **Symmetric Photo Gallery & Lightbox**: Features a custom 6-column desktop grid for a balanced 5-item gallery, loading a full-screen blurred backdrop modal with titles and descriptions dynamically upon interaction.
* **Dynamic viewport Counter**: Stats numbers dynamically increment from `0` to their official target counts (e.g. `50,000+` distributed meals) in exactly 2 seconds when entering the viewport.
* **Fully Responsive**: Adapts fluidly across 4K displays, desktops, tablets, and small-screen mobile layouts with custom hamburger overlays.
* **Authentic Indian Photography**: Replaced generic international templates with realistic documentary-style photography depicting real volunteering drives, classrooms, street-dog feeding, and sapling plantation campaigns.

---

## 🛠️ Technology Stack

* **Structure**: HTML5 (Semantic & SEO-optimized)
* **Styling**: Vanilla CSS3 (Custom Grid layouts, Keyframes, Custom cubic-bezier Transitions)
* **Logic**: Vanilla ES6+ JavaScript (Intersection Observers, ARIA accessibility bindings, Modal controllers)
* **Icons**: FontAwesome v6.4.0 (Vector Icons library)
* **Typography**: Outfit & Plus Jakarta Sans (Google Fonts)

## 🚀 How to Run Locally

Since this is a lightweight static website, you can run it instantly using any local HTTP web server.

### Option 1: Python HTTP Server (Recommended)
Since Python is already installed, open PowerShell or Command Prompt in the project folder and run:
```powershell
python -m http.server
```
Then, open your web browser and go to:
```text
http://localhost:8000
```

### Option 2: VS Code Live Server Extension
If you are using Visual Studio Code:
1. Open the project folder in VS Code.
2. Install the **Live Server** extension.
3. Click the **Go Live** button at the bottom-right status bar.
